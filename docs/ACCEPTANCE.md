# ShanghaiCiv 验收矩阵与质量门禁（Acceptance & QA）

> **版本** v1.0 · **状态** Proposed。以下均为**未来验收计划**，不是已经完成的测试结果。  
> 需求：[PRD](./PRD.md) · 实施计划：[IMPLEMENTATION_PLAN](./IMPLEMENTATION_PLAN.md)

## 1. 分阶段门禁

| Gate | 所属阶段 | 核心门槛 | 允许后续 |
|---|---|---|---|
| **G0 工程** | P00 | 可复现安装/运行测试，PR 规则、CI 和文档入口齐全 | 数据调查 |
| **G1 可行性/许可** | P01 | 核心源真实可用，地图授权与公开合规路径明确，列出阻塞项 | 真实数据/地图实现 |
| **G2 数据合同** | P02 | 数据结构、单位、年份、CRS 和 null 语义冻结；反例测试通过 | ETL/GIS |
| **G3 统计可信** | P03/P06 | 每个展示数字具来源/期/单位，错误源与冲突数据会触发 FAIL | 经济图层 |
| **G4 地理可信** | P04/P05 | 16区对齐，岛屿/水域合理，授权几何与坐标转换核验完成 | 可见地图 |
| **G5 体验** | P07-P10 | 核心旅程、图层、Almanac、移动端、性能目标达到或有批准的例外 | 发布候选 |
| **G6 公开发布** | P11 | G0-G5 适用项 PASS + 数据再分发及地图展示合规审查已完成 | GitHub Pages |
| **G7 维护** | P12 | 更新可审计、可回滚、许可与统计期不退化 | 持续更新 |

原则：**G6 是强制阻塞门禁**。任何自动化脚本/Agent 不得将缺少合规证据的页面发布为上海官方/真实地图。

## 3. 数据质量自动断言（DQ）

| DQ ID | 检查 | 严重级别 |
|---|---|---|
| DQ-001 | 16 区实体数量=16，ID 唯一，名称/区划编码与官方核验版一致 | FAIL |
| DQ-002 | 所有展示指标 `source_id`、`period`、`unit` 不为空 | FAIL |
| DQ-003 | `value=null` 必须明确指示 unavailable/未提供，不用 `0` 代替 | FAIL |
| DQ-004 | 指标的 `granularity` 与其展示所在空间统计单元一致 | FAIL |
| DQ-005 | 同一排行指标的单位、统计期/定义一致，不可比的值排除或阻断 | FAIL |
| DQ-006 | 同一网格 ID 在 Python/JS 中中心坐标及邻接一致 | FAIL |
| DQ-007 | 每条公开几何/瓦片/资产的许可状态符合实际再分发/访问方式 | FAIL / 人工签署 |
| DQ-008 | source cache hash 与 manifest 一致 | FAIL |
| DQ-009 | 合同要求数组、索引、可空字段与数值范围正确 | FAIL |
| DQ-010 | 地形/专题无数据占比超预算（阈值须按源设定） | WARN；涉及主功能则阻塞评审 |
| DQ-011 | 发布年度/来源版本变更前后差异报告齐全 | WARN；未经批准不可上线 |
| DQ-012 | 公开 JSON 无受限 raw、令牌或个人敏感内容 | FAIL |

### 验证用例实例

- **例一：伪精度**：为某区录入一个 2024 年的区级人口值；若 builder 把它拆成每个 1 km 格网的 `observed` 值，测试必须 FAIL。
- **例二：缺失值**：对「示例区」GDP 写入 null；界面应显示「暂无数据」，不应显示 0 或被计为 GDP 最低区。
- **例三：混合年份**：A 区 2024，B 区 2025；无可比性说明时不能直接排行。
- **例四：面积计算**：人口密度属于 derived 时，人口与面积统计期/范围不一致需拒绝。
- **例五：地图边界**：中心点在区外、六边形有 20% 面积在区内时应保留 partial/多边界信息，而非将行政边界凭空移动到格网边。
- **例六：许可**：来源授权 unknown 时 `publish_approved` 必须被拒绝。

## 4. E2E 用户旅程

### E2E-01 基础地图

1. 打开本地/受控预览；
2. 检查全图可见及 UI 稳定；
3. 搜索一个真实的上海区并选中；
4. 缩放和拖动，再点击复位；
5. 复制 URL；新标签页打开并恢复相同视角/选区。

**通过**：没有 console error、关键状态正确。

### E2E-02 可信统计

1. 选择人口密度图层；
2. 点击两个区，查看值、单位、年份、来源；
3. 前往 Almanac；
4. 切换 GDP；若不可用显示明确缺失信息；
5. 使某个指标服务/文件请求返回 404，检查降级。

**通过**：数字→来源链通畅，无不明假值。

### E2E-03 移动端/键盘

1. 设置 375×812 视口；
2. 点击搜索、选择区、切换图层、关闭面板；
3. 仅通过键盘完成搜索和面板导航；
4. 测试屏幕缩放与宽度 320/375/768/1440。

**通过**：核心控件不互相遮挡、焦点可见、交互无死区。

### E2E-04 同步探索

1. 选择两个区；
2. 选择同年、同单位的两个指标；
3. 观察表格/散点图/地图同亮；
4. 切换某个无数据指标。

**通过**：高亮一致，空值不错误排序。

## 5. 性能基准（待实际测量）

**注意：均为目标，不是 USACIV 或本项目已达成绩。**

| 测项 | 首版目标 | 测量约束 |
|---|---|---|
| 初次页面静态数据下载 | 初始包 ≤15 MB | 记录缓存开/关、网络条件 |
| 交互帧率 | 桌面目标 ≥45 FPS | 标注硬件、DPR、分辨率、场景与统计分位 |
| 移动帧率 | 主流手机目标 ≥30 FPS | 标注设备型号、浏览器版本 |
| 缩放/平移响应 | 无持续卡顿或肉眼明显闪烁 | 检查长任务和缓存命中 |
| 可用性 | 关键旅程 E2E 100% PASS | 明确浏览器版本和测试日期 |
| 内存 | 不随反复图层切换无界增长 | 记录 10 分钟测试过程 |

当目标未达到时，保留性能 profile 与明确的降级方案；不得简单将未测项目标记为 PASS。

## 6. 发布门禁记录表（发布前填写）

```markdown
# ShanghaiCiv Release Gate
Release ID: ...
Build SHA: ...
Dataset manifest SHA: ...
Review date: ...
- [ ] G0 工程
- [ ] G1 数据与地图许可（证据链接：...）
- [ ] G2 数据合同
- [ ] G3 统计可信
- [ ] G4 GIS/16区对齐
- [ ] G5 交互/E2E/性能
- [ ] 图像/字体/第三方代码权利检查
- [ ] 地图审核/审图号/新增标注/署名（适用结论与证据：...）
- [ ] 公开部署授权负责人签署：...
Decision: APPROVED / BLOCKED
```

**发布规则**：除非 `Decision=APPROVED` 且必要证据可查，deploy 工作流不应公开新的地图构建产物。文件本身的存在不能替代实际审核签署。
