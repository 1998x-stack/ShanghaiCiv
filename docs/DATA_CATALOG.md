## 3. 数据源状态机（必须写入 manifest）

```text
discovered → metadata_reviewed → license_reviewed → accessible
      ↓                 ↓               ↓
   rejected         blocked         restricted
      ↓
accepted → raw_cached → normalized → quality_checked → publish_approved
```

**禁止**把 `discovered` 自动升级为 `publish_approved`。

每个来源的注册信息至少包括：

```yaml
source_id: SRC-001
title: 上海统计年鉴2025
publisher: 上海市统计局
homepage: https://tjj.sh.gov.cn/tjnj/tjnj2025.htm
dataset_url: null                   # 精确表链接确认后填写
retrieved_at: null                 # 尚未实际下载，不能填当日为抓取日期
reference_period: "2024"           # 仅适用于已证实的目标表，不能应用于整本年鉴
release_date: null
geographic_granularity: district
crs: null                          # 无几何/坐标的统计表应为 null
unit: null                         # 应在单个指标级补足
license_status: unknown            # unknown/allowed/restricted/prohibited
redistribution_allowed: null      # 必须有证据
attribution_required: null
api_auth_required: null
status: metadata_reviewed
sha256: null                       # 实际下载后才能计算
reviewer: null
notes: "仅已定位官方目录，下载和再发布条件待核对"
```

## 4. 字段质量与可比性

**每条正式展示值至少要求**：
- 唯一 `metric_id` + `geography_id`；
- `reference_period`（注明期初/期末/全年等）；
- `unit` 及换算规则；
- `status`（observed/derived/estimated/unavailable）；
- `source_id`、可解引用的出处 URL；
- `method_id`（用于派生值），解释计算规则；
- `quality_flags`（revision/partial/ambiguous/noncomparable 等）。

**自动失败条件**：
- 已展示数值缺少来源或年份；
- 区级值在界面标签中被宣称为格网级实测；
- 数值 `0` 代替缺失/未知；
- 单位不一致仍作比较；
- 被标注 `publish_approved` 的源没有授权或审核证据；
- `sha256` 与缓存实体不符；
- 某区代码重复、对象跨行政区引用有冲突。

**人工复核事项**：
- 16 区名称和所选年度代码；
- 年鉴表与统计公报统计口径不同；
- GDP 修订与统计普查结果导致历史数值变化；
- 数据版权/许可与公开展示之间的具体差异；
- 地图成果/底图的审核与图层内容的适用要求。
