# 游戏化指标映射预案（P02-T06）

> **状态：禁用 / 未发布**。本文件只有规则设计约束，**没有**为上海生成粮食、生产力、金币、科学或文化分数。

## 核心原则

- 美术上的产出图标不是客观测量本身；显示时必须标注原始统计单位、年份、地域尺度和 proxy（代理指标）。
- 不应直接使用美国 USACIV 的就业行业对应规则推断上海经济能力；中国统计口径可能不公开等价区级就业分布。
- 统计来源粒度不足则**不启用**任何 hex 级产出值；不能将区级值平均分摊至 hex 并伪称观测。
- 必须登记 `method_id`、原始字段、来源、计算公式、统计期、单位转换、缺失条件、解释局限。

| 游戏符号 | 候选现实代理 | 数据需求 | 状态 |
|---|---|---|---|
| 🌾 Food | 粮食产量或农业相关就业 | 区级农业指标、明确口径 | **DISABLED** |
| ⚙️ Production | 制造业生产、工业就业或增加值 | 工业/制造业官方字段，明确区别总产值/增加值 | **DISABLED** |
| 🪙 Gold | 地区生产总值 | 同年且修订状态一致的区级 GDP | **DISABLED** |
| 🔬 Science | 科技研发投入/科技创新活动 | R&D/研发人员/科研机构等可比指标 | **DISABLED** |
| 🎭 Culture | 文化产业或公共文化资源 | 同口径统计与教育文化设施 | **DISABLED** |

## 强制发布条件

1. 每个符号必须在 `metrics` 中有合法 source、period、granularity、unit、status。
2. 代理指标明确标识 proxy，不得暗示食物产出是粮食总产量（若原数据仅为农业就业）。
3. 公式变动增加 `method_id` 版本并做可审计数据差异。
4. 对缺失区使用 `null` 和缺失样式；不补 0，不生成没有依据的游戏点数。
5. AI Agent 不得擅自打开或宣称游戏化映射已可供真实地图使用。
