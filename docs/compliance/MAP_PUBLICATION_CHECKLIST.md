# ShanghaiCiv 地图使用与公开发布合规调查清单（P01）

> **日期**：2026-11-27 · **结论**：**BLOCKED / 未获公开发布准入**  
> **性质**：项目资料调查，不构成专业法律意见、行政审批或监管机关答复。  
> **参照**：[上海市地图管理办法](https://www.shanghai.gov.cn/xxzfgzwj/20210713/0fbc6abe525e458eaa4cf8b921cc0767.html) · [天地图·上海条款](https://shanghai.tianditu.gov.cn/map/views/about.html?type=1) · [公共数据开放实施细则](https://www.shanghai.gov.cn/202307bmgfxwj/20230417/6c6372813aca46e7a004d83dea12e045.html)

## 1. 调查结论与证据

### 1.1 上海市地图管理要求

从市政府公布的《上海市地图管理办法》查到：

- 第七条：地图编制应符合国家有关地图编制标准，涉及测绘资质与内容规定。
- 第八条：公益性地图用于教育教学、宣传示意等并保留原审图号时，不得影响行政区划名称、区界、重要地名。
- 第九、十条：公开地图需依法判断审核范围；以本市为主要表现地的地图按规定报市规划资源部门审核，由展示/登载者等依法送审。
- 第十四条：通过审核的地图获得批准及审图号，互联网地图服务的标注位置有规定。
- 第二十五条：互联网地图服务要求使用依法审核批准的地图，并做好新增标注核查、数据安全与备案（具体是否归入此类别由正式主体/主管部门确认）。

上述是**与本项目相关的规则信息**，并不自动推定任何方案已经取得批复，也不自行宣称项目一定属于某一豁免类别。

### 1.2 天地图·上海使用条款

官网介绍为上海市测绘院建设的在线地理信息公共服务门户；条款要求遵守地图法规、不得恶意干扰服务；版权声明称所提供内容由数据及资料提供方持有，使用者须注明来源；转载引用要求注明“转自（或引自）天地图·上海”和网址。

**已知**：官方站点和条款可以访问，提供地图与 API 资源入口。  
**未知**：是否允许本项目将区界下载为 GeoJSON，是否允许批量瓦片缓存/离线供图、对在线地图做六边形遮罩和新的行政/功能区标注、地图截屏和转存、GitHub Pages 公开嵌入，以及有无额外服务 Token/备案要求。

**官方联系入口**：[关于我们 / 联系我们](https://shanghai.tianditu.gov.cn/map/views/about.html?type=1)，联系电话 **021-62549550-8452**；工作时间见官网。

### 1.3 上海公共数据开放平台与统计数据

《上海市公共数据开放实施细则》规定无条件开放数据可直接通过平台下载或 API 获得，有条件开放须申请并遵守数据利用协议；成果注明来源并遵守利用场景限制。是否允许打包/再分发由**具体数据集的现行协议**判断，不可将网页可阅读等同于开源许可证。

研究快照放置 `data/research/`，并明确标记 `NOT_PUBLISH_APPROVED`。**不是放入公开仓库就代表已获得后续生产使用授权。** 若经确认研究数据公开存储本身不符合要求，必须从远程历史中清除并采取适当访问策略；不允许简单删除工作树就认为 Git 历史也已移除。需由负责人尽快核对公共事实性数据与数据库使用条款。

## 2. 方案 A / B：需要外部确认的地图实现路径

| 方案 | 结构 | 优点 | 需要确认 | 当前状态 |
|---|---|---|---|---|
| A 官方在线底图 + 统计覆盖 | 通过合法地图服务/SDK 显示上海，业务自行绘制交互层/数据 panel | 降低自行维护底图与国界/区界风险 | API 授权、Token、坐标系统、允许叠加范围、审核和页面署名 | **优先建议，待确认** |

| C 文档/合成图形原型 | 只展示无真实上海几何的 synthetic 六边形和研究方法 | 可并行验证前端和算法 | 图形必须标注 synthetic，不能误称上海地图 | **P02 可先行** |

### 推荐决策程序

1. 整理项目功能清单：全域地图、16区、1 km 网格、GIS 坐标/点击、专题填色、地标、分享截图、静态站点；
2. 将方案 A 与 B 各自示意图/服务调用方式交给地图服务提供方确认书面许可；
3. 根据上海市地图管理规范，向有权部门确认此站点的送审、备案、审图号、更新/新增标注义务；
4. 审核源码、真实矢量数据、瓦片缓存、导图功能是否可公开分发；
5. 记录批准文件/条款/联系人/日期与使用范围在 `docs/compliance/`；未取得证据时禁止上线。

## 5. GitHub 工程执行红线

- `web/data/` 只能接收 publish-approved 数据，`data/research/` 下的研究快照默认不能被 build 命令读取；
- GitHub Actions `deploy` 默认禁用/在审批环境下运行，不应在无合规凭证时发布真实地图；
- 档案内不得放置未获再分发许可的区界、道路矢量、商业瓦片或 API 凭证；
- 若审批结果不支持方案 B，按 ADR 选择 A 或变更要求，不通过未经核对的第三方地图跳过审核；
- 所有发布时的来源、许可、审图/署名信息在 UI 中可见，文件版本可溯源。
