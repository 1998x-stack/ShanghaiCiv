# ShanghaiCiv｜地图程序化美术设计规范（P09）

> **仅对 synthetic art baseline 生效**。此项目未取得《文明》系列游戏美术版权许可，也不使用游戏图标、贴图、背景音乐或商标素材。全部地图小物件为自己实现的 Canvas 原始几何形状。**原型场景并非上海地理。**

## 视觉原则
- 专题先于装饰：P08 中真实统计粒度（此处仅虚构区级）按区域 Polygon 整体着色；图例、来源与缺失说明必须保留。
- 美术不改变区属：P04 的陆/水/未分类覆盖、hex ID、区界和海岛洞绝不能由装饰模块重写。
- 错误解读优先于美观：任何地标、树、厂房仅为**程序化造型**，不是实际设施 POI；不得从装饰密度推断经济繁荣。
- 来源边界：所有场景必须是标记 \`synthetic=true\` 的合成 JSON，真实 EPSG/CGCS 等需独立许可与数据验证。
- 字体使用系统 \`system-ui\`；不依赖第三方 CDN、付费字库、商业游戏素材或在线瓦片。

## 四级 LOD

以 \`pixelsPerHexRadius = camera.scale × grid.radius_m\` 作为阈值：

| LOD | 像素半径区间 | 每个完整、非混合单元最多装饰数 |
|---|---|---:|
| Overview（远景） | <22 px | 0 |
| Regional（中景） | 22–47.99 px | 2 |
| Local（近景） | 48–94.99 px | 5 |
| Detail（局部） | ≥95 px | 9 |

- 默认自动选级，也允许手动覆盖以审核四级美术。
- 只在足够确定的单一陆地或水域单元绘制；partial 或大量未分类格子不强行生造某种具体地表。
- 物件位置由 \`ShanghaiCiv-P09-SYNTHETIC-V1\` 固定种子与 cell ID、LOD 导出，拖动和刷新不会产生随机闪烁。LOD 阈值跨越时出现增减细节是预期的渐进展示，不是实际地物增减。

## 缓存与性能预算

- 每地图会话采用 **160 项** LRU 描述符缓存（ArtCache 可配置；支持最小 1、最大 4096 项）；
- 缓存键包含固定种子、cell ID、LOD 和陆/水类型，不使用真实坐标、个人位置或任何私人状态；
- 不持有 Canvas DOM、外部图片 URL 或 GPU texture；存储只有有限尺寸的矢量描述符；
- 运行时报告 entries/limit、hits、misses、evictions 与当帧绘制数量；
- 复用 P04 \`visibleCells\` 视窗裁剪：不会每次重绘遍历全部扩展城市网格；
- 先保证浏览器 E2E 与确定性，再进行 56 格之外的 FPS、峰值内存、设备能耗定量基准。未测试生产地图性能不得宣称达标。

## 标签与可访问性

- 虚构四类原型名称：虚构金融城、虚构科技园、虚构交通枢纽、虚构制造港。
- 标注类型分别对应**非**陆家嘴、张江、虹桥、临港，且没有现实的坐标、园区边界、经济指标；不使用真实地名作为合成场景地理。
- 标签优先级：虚构类型标注高于虚构大区名；使用确定性排序、矩形排斥测试、防截断，防止地图标签互相覆盖。
- 主 HTML 的图层/LOD 开关有 label 与键盘控件；地图键盘操作沿用 P07；不通过颜色单独表达缺失值或许可。
- \`art.html\` 四视图均有文字 LOD、原创场景声明和可阅读的缓存指标。
