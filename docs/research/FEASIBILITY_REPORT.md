## 1. 执行结论

### 可以开始的工作

- **行政区主数据可用**：上海市民政局于 2026-07-27 发布最新可见的区划代码表（对应截至 2026-06-30），16 个区的 6 位行政区代码可以由官方文件核对；原文还列乡镇/街道编码。必须注意 2026 区划代码和 2024 统计值不同年份。[民政局代码表](https://mzj.sh.gov.cn/MZ_zhuzhan1539_0-2-8-1459/20260727/535996b5abd045baac0c65552f4527d9.html)。
- **16区统计基础可靠**：2025《上海统计年鉴》表 2.2（2024 期）逐区给出面积、常住人口、外来常住人口、密度；表 12.2（2024 期）逐区给出工业企业主要指标；表 14.6（2024 期）逐区给出规模以上服务业企业主要指标；表 10.17（2024 期）逐区给出绿化面积和公园数等。四表均能在官方 HTML 浏览器界面逐条读取。**这些是区级统计，不是格网级统计**。
- **至少4种区级专题有事实依据**：常住人口规模、人口密度、工业企业工业总产值、规模以上服务业营业收入、绿地面积、公园数量。具备数据覆盖 ≠ 已核实公开再分发权、也 ≠ 已完成专题页面。
- **开放平台制度可用**：无条件开放数据可通过平台下载/API 直接获取；有条件开放数据要申请、按数据利用协议使用。交通/公园 POI 的具体可用数据集仍须逐条核实，不得将平台示例页面视为已经授权。[上海公共数据开放实施细则](https://www.shanghai.gov.cn/202307bmgfxwj/20230417/6c6372813aca46e7a004d83dea12e045.html)。
- **地图接入路径存在，但尚未达到准入**：天地图·上海提供在线服务，官方说明其地图内容由各提供方持有权利，引用须标注来源。自行导出瓦片/矢量几何、离线缓存、程序化改图的使用权限仍不明确。[天地图·上海服务条款与版权声明](https://shanghai.tianditu.gov.cn/map/views/about.html?type=1)。

## 4. 来源/API 与许可评估

### 4.1 可直接访问的统计数据

2025 年上海统计年鉴目录：[官网](https://tjj.sh.gov.cn/tjnj/tjnj2025.htm)。上述四表均是浏览器可读取的 HTML 表，**不需要平台个人账号才能查看**；在研究阶段可明确每个区的值和它所属的指标。

但 P01 尚未取得允许**批量下载、再发布 JSON**的明确授权；平台的「公开网页」与产品的「可复制/开放许可」不是同一个结论。需咨询统计局或找到明确适用的使用说明。可用字段先行在 `data/research/` 下作为审核材料，不复制整个来源网页。

### 4.2 上海公共数据开放平台

- [平台](https://data.sh.gov.cn/)支持无条件/有条件开放数据两类，官方制度要求有条件类在页面列出用途与安全条件；
- 官网 [2025 操作指南](https://data.sh.gov.cn/assets/data/上海市公共数据开放平台操作指南20250527V3.0.0.pdf) 说明数据资源详情、API 文档、申请/审批及下载的使用路径；其示例涉及**全市地铁进出客流量**等有条件数据，不可凭示例宣称已下载/获批。
- 《实施细则》第二十九条等要求利用成果注明数据来源；数据使用协议可能限制应用场景及再分发。

**结论**：后续 P05 可以优先验证「公园绿地名录」类的无条件开放资源，但仍需拿到具体 data resource ID 和当期协议；轨交客流不可默认有开放调用资格。

### 4.3 天地图·上海

- [天地图·上海](https://shanghai.tianditu.gov.cn/)由上海市测绘院建设/提供地理信息服务，网站有地图 API/数据 API 入口；

- 官方联系信息：**021-62549550-8452**，工作时间官方页面列为周一至周五 08:30–16:30；可咨询业务接入/叠加及地图审核路径；

## 5. GIS 方案前置技术验证

不应把 Karpathy 的美国 Albers 参数直接搬到上海。P02/P04 需要：
1. 确定官方底图采用的 CRS 与输入矢量数据 CRS，完成 GCJ-02/WGS84/CGCS2000 等坐标匹配审查；
2. 选择适合上海的米制平面 CRS，规定投影公式、原点、坐标单位、精度；
3. 用不含真实地理形状的**synthetic geometry** 测试 R=0.5/1/2 km 网格；
4. 统一 odd-r hex Python/JS 几何算法，测试 island/water partial cell；
5. 用获得许可的真实上海地理数据核对陆地/江面/区界；未获许可前保持 BLOCKED。
