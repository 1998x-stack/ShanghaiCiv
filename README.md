# ShanghaiCiv

> 上海真实数据驱动的文明风格交互地图（项目规划阶段）

ShanghaiCiv 旨在将上海全域地理、16 区人口与经济、产业、交通、公共设施等有明确来源的数据，转化为可交互、可溯源、适合长期更新的城市知识地图。设计参考 [USACIV](https://karpathy.ai/usaciv/) 的数据流水线与六边形渲染理念，但不将区级统计数据伪装为格网级事实。

**状态：** 需求与数据可行性论证中；尚未完成地理数据许可与公开地图展示合规审查。未经验证的数据不得标为真实值。

项目文档在 `docs/` 下按 PRD、实施阶段、数据来源、架构及验收分层维护。

## 项目边界

- 首版覆盖上海全部 16 个区；建议以 1 km 半径六边形作为可调候选，而非已定地理事实。
- 官方统计指标按实际可得的市、区或街镇尺度展示；地形和设施可以与格网关联。
- 数据来源、统计年份、授权状态和质量限制必须可查。
- 所有公开地图输出都须符合底图服务条款、地图审核和标注要求。
